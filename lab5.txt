LAB 5 - MONGODB COUNT, SORT, LIMIT, SKIP AND AGGREGATE

WHAT THIS LAB DOES
You will insert employee records into MongoDB and run queries to:
1. Count employees
2. Sort employees by salary
3. Display only a limited number of records
4. Skip records
5. Use aggregate operations

WHERE TO DO IT
Use MongoDB Shell (mongosh). Do not type these commands into the normal Ubuntu shell.
Open mongosh first; then type the MongoDB commands below.

A. START MONGODB SHELL

If MongoDB is already installed and running:
   mongosh

If you use MongoDB Compass, you can open its embedded shell or connect with mongosh.
MongoDB Server must be running before the shell can query your database.

B. SELECT A DATABASE

At the mongosh prompt, type:
   use company

D. QUERY 1 - COUNT EMPLOYEES

db.employee.aggregate([
  {$group:{_id:null,totalEmployees:{$sum:1}}}
])

EXPECTED OUTPUT
{ "_id": null, "totalEmployees": 14 }

E. QUERY 2 - SHOW FINANCE EMPLOYEES, HIGHEST SALARY FIRST

db.employee.aggregate([
  {$match:{Department:"Finance"}},
  {$project:{name:1,age:1,Department:1,Gender:1,salary:1}},
  {$sort:{salary:-1}}
])

EXPECTED OUTPUT (sorted by salary)

MOHAMMED ARSHAD  Finance   Male     750000
Kavana           Finance   Female    90000

G. QUERY 4 - SHOW THE TOP TWO PAID FINANCE EMPLOYEES

db.employee.aggregate([
  {$match:{Department:"Finance"}},
  {$project:{name:1,age:1,Department:1,Gender:1,salary:1}},
  {$sort:{salary:-1}},
  {$limit:2}
])

H. QUERY 5 - SKIP THE FIRST SIX EMPLOYEES

db.employee.find().sort({_id:1}).skip(6)

EXPECTED OUTPUT

Ananya, SHIVANI K K, VARSHA G R, Shifa Banu and MOHAMMED ARSHAD.

I. QUERY 6 - SKIP THE FIRST TWO FINANCE EMPLOYEES AFTER SORTING

db.employee.aggregate([
  {$match:{Department:"Finance"}},
  {$project:{name:1,age:1,Department:1,Gender:1,salary:1}},
  {$sort:{salary:-1}},
  {$skip:2}
])

EXPECTED OUTPUT
Kavana           Finance   90000
Ruthvi R Chawla  Finance   90000
Rajesh           Finance   40000
Akash            Finance   40000

WHAT THE WORDS MEAN
$count / $sum: count how many records there are.
$match: choose only records matching a condition.
$project: choose which fields to show.
$sort: arrange records. -1 means descending; 1 means ascending.
$limit: show only the first N records.
$skip: ignore the first N records.
$group: put records into groups and calculate values.
